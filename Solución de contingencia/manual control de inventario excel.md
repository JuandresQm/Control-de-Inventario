Manual de usuario

El sistema de inventario opera de manera secuencial a través de cinco apartados. Para utilizar el sistema de manera correcta, primero se deben llenar manualmente los Parámetros para configurar las categorías, unidades de medida y umbrales, luego se registra el Catálogo de productos combinando automatización y selección, y en tercer lugar se realiza el Registro de conteo de stock como chequeo físico inicial de las existencias. Una vez completados estos tres pasos fundamentales, el sistema queda listo para operar el flujo diario mediante los historiales de Entradas y Salidas y la consolidación automática en el Balance y valoración de stock.
El catálogo de productos contiene los siguientes datos: SKU, nombre del producto, categoría y unidad de medida. Aquí se ingresan los datos de todos los productos del almacén y cuenta con tres formas de llenado: el SKU se genera automáticamente a partir de la categoría y el nombre del producto, el nombre del producto es ingresado manualmente por el usuario, y tanto la categoría como la unidad de medida se seleccionan de listas predefinidas en el apartado de Parámetros.
El registro de conteo de stock es el segundo paso para el uso del sistema y representa el chequeo físico inicial necesario para llevar el control de las existencias. Este contiene los siguientes datos: Auditoría ID, SKU ID, ubicación en almacén, stock físico inicial y fecha y hora de conteo.  Cuenta con tres formas de llenado: la Auditoría ID se genera de forma automática, el SKU ID se selecciona mediante una lista de opciones predefinida en el catalogo, y la ubicación en almacén, el stock físico inicial y la fecha y hora del conteo son ingresados manualmente por el usuario.
Los historiales de Entradas y Salidas del almacén contienen los siguientes datos: ID de la entrada o salida, identificador de control que representa el número de factura o número de lote, SKU ID, cantidad y fecha. Ambas secciones registran los flujos de mercancía y cuentan con tres formas de llenado: el identificador principal se genera automáticamente de forma secuencial, los datos de control, las cantidades y las fechas son ingresados manualmente por el usuario, y el SKU ID se selecciona de una lista predefinida del catálogo de productos.
El balance y valoración de stock contiene los siguientes datos: SKU ID, nombre de producto, stock inicial, total de entradas, total de salidas, stock actual disponible y el estado del inventario que indica si es necesario hacer restock. Aquí se consolidan las existencias del inventario y cada campo se llena de manera automática con base en los demás apartados. En el apartado de Parámetros se puede indicar cuál es el stock mínimo de alerta.
El apartado de Parámetros contiene los datos base que alimentan las listas desplegables y reglas del sistema, tales como categorías de productos, unidades de medida y la cantidad mínima general para restock. Aquí se configuran los valores iniciales y cuenta con una forma de llenado manual, ya que los usuarios ingresan y actualizan directamente las opciones permitidas y los umbrales de alerta según las necesidades del almacén.
